The Plenty language
Why not have it all?

A statically-typed language based on Python and Rust. Familiar syntax, checked ownership, efficient memory management. Write clear programs that compile fast to native code.

def first_warning(lines: &[str]) -> Option[str]:
    for line in lines:
        if line.startswith("WARN "):
            return Some(*line)
    Nothing

def main() -> Result[(), AllocError | IoError]:
    lines = ["INFO Ready", "WARN Disk almost full"]?
    match first_warning(&lines):
        case Some(warning):
            print(warning)?
        case Nothing:
            print("No warnings")?
    Ok(())

Find the first warning

  • Pythonic syntax. Indentation, a for loop, and a list literal keep the search readable.
  • Rust-style sum types. Option represents a warning or its absence. match handles both.
  • Fallible allocation. The list literal can fail. ? passes that error back as part of Result.
  • Checked borrowing. &lines lets the search read the list without copying it or taking ownership.

Familiar shape

Readable Pythonic syntax. Polymorphic protocols. Rich standard library. List comprehensions? You betcha! Rust-like Result and Option.

Clear contracts

Borrow checker like Rust. Fallible allocations. No runtime panic allowed. Errors and allocation failures appear in function signatures. No garbage collector. No exceptions.

Native by design

Compile to a native executable. No interpreter, virtual machine, or garbage collector required. Precise struct layout.
