The Plenty language
Why not have it all?

A statically-typed language based on Python and Rust. Familiar syntax, checked ownership, efficient memory management. Write clear programs that compile fast to native code.

Familiar shape

Readable Pythonic syntax. Polymorphic protocols. Rich standard library. List comprehensions? You betcha! Rust-like Result and Option.

Clear contracts

Borrow checker like Rust. Fallible allocations. No runtime panic allowed. Errors and allocation failures appear in function signatures. No garbage collector. No exceptions.

Native by design

Compile to a native executable. No interpreter, virtual machine, or garbage collector required. Precise struct layout. 

def main() -> Result[(), AllocError | IoError]:
    lines: array[str, 3] = [
        "INFO Ready", "> > WARN Disk almost full", "WARN High CPU",
    ]
    found = [line for line in warnings(&lines)]?
    match found.get(0):
        case Some(first):
            print("Warnings:", len(found), "| First:", first)?
        case Nothing:
            print("No warnings")?
    Ok(())

def warnings[const N: i64](log: &array[str, N]) -> Generator[str]:
    for line in log:
        if is_warning(*line):
            yield *line

def is_warning(line: &strview) -> bool:
    if line.startswith("> "):
        return is_warning(&line[2:])
    line.startswith("WARN ")
  • Pythonic syntax. Indented blocks and a list comprehension keep the filtering readable.
  • Rust-style sum types. match handles both cases of Option. The anonymous sum AllocError | IoError lets Result carry either error type.
  • Tail-call optimization. Each recursive call to is_warning strips one forwarding prefix without growing the stack.
  • Allocation-free generators. yield produces one warning at a time without allocating a generator frame on the heap.
  • Fallible allocation. The fixed array is stored inline. The comprehension builds a heap list and ? propagates allocation failure.
  • Checked borrowing. &lines lends the array to the generator. The compile-time N lets the same function accept arrays of any length.
  • And much more.
