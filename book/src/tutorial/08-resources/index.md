# Useful programs and resources

Turn external text into values, format results, and connect your program to
arguments, standard streams, and files. Whole-file helpers cover simple jobs;
`with` keeps a resource available for a block and closes it on exit.

Finish by composing these operations into a small command-line application.
Detailed text method examples and uncommon file operations are supplementary
reference material, so they need not interrupt this learning path.
