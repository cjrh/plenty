# Scrollable

![iced Scrollable example window](screenshots/scrollable.png)

Scroll one child vertically within a fixed-height viewport. Use a column as the child for multiple rows. Close the group with `end()`.

From `examples/gui/iced_widgets`, run `plenty run --bin scrollable`.
