# Supplementary examples

These examples complement the [core learning path](../../tutorial/index.md).
Use them to look up a particular operation once you understand ownership,
borrowing, and recoverable errors.

See [collections and iteration](../facilities/01-builtins/collections.md),
[owned files](../facilities/02-io/files.md), and [text stream positions](../facilities/02-io/positions.md)
for the corresponding contracts and limits.

The [finder experiment](finder.md) tests these facilities against a realistic
CLI task and records where the implemented surface still blocks it.
