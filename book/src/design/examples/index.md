# Supplementary examples

These examples complement the [core learning path](../../tutorial/index.md).
Use them to look up a particular operation once you understand ownership,
borrowing, and recoverable errors. Their programs and expected diagnostics are
checked by `cargo test --test test_tutorial`, just like the tutorial.

The following pages cover collection operations, text methods, and advanced
file operations. See [collections and iteration](../05-current-language-contract/08-collections-and-iteration.md),
[owned files](../17-owned-files.md), and [text stream positions](../20-text-stream-positions.md)
for the corresponding contracts and limits.
