# Support index

The reference describes the supported subset, not Python's full API. Detailed
restrictions live with their contracts.

| Area | Contract and principal limits |
|---|---|
| Source and modules | [Declarations, imports, visibility, and entrypoints](../../language/02-source/index.md); [compile-time constant expressions, static assertions, and included files](../../language/02-source/modules.md#constants); [`if const` target conditionals](../../language/02-source/target-conditionals.md) over a closed set of target facts; one source root per package, no import cycles or re-exports |
| Packages | [`plenty.toml`, path and Git dependencies pinned in `plenty.lock`, version requirements, workspaces, `plenty add`/`fetch`/`update`, per-target build reuse, debug/release profiles, `plenty test` with per-process test functions run in parallel under optional timeouts, and `plentyc --package-graph`](../01-building/packages.md); no registry or version selection |
| Types and data | [Types](../../language/03-types/index.md), including [byte literals](../../language/03-types/bytes.md) of type `bytes`; fixed layouts and recursive data through heap boundaries; read-only `std.bytes` operations and stream writes take `bytes` or `Bytes` through `std.bytes.ByteSource` without copying |
| Expressions | [Operators, assignment, and control flow](../../language/04-expressions/index.md); blocks and expressions [nest to 64 levels](../../language/04-expressions/index.md#nesting); [f-strings](../../language/04-expressions/format-strings.md) with any expression as a field and compile-time Python format specs, whose nested fields supply only fill, alignment, width, and precision; copying [slices](../../language/04-expressions/slices.md) `xs[a:b:c]?` of lists, text, bytes, tuples, and clists; local [slice views](../../language/04-expressions/slices.md#slice-views) `&xs[a:b]` of lists and bytes, typed `&[T]`, and of text, typed [`&substr`](../../language/04-expressions/slices.md#substring-views); no slice assignment |
| Ownership | [Moves, checked borrows, returned references including `Option[&T]` and `Result[&T, E]`, and cleanup](../../language/05-ownership/index.md); general stored references unsupported |
| Functions | [Named functions and concrete closures](../../language/06-functions/index.md); [named arguments and fresh per-call defaults](../../language/06-functions/01-signatures-and-calls.md) for static calls, with callable/builtin/protocol restrictions; explicit fallible [shared-call erasure](../../language/06-functions/05-boxed-callables.md) |
| Generics | [Concrete specialization and structural protocols](../../language/07-generics/index.md), including requirements with their own protocol-constrained type parameters; methods of a generic class or enum instance are checked and compiled only when used; no dynamic protocol dispatch |
| Errors and resources | [Sums, propagation, allocation, and context scopes](../../language/08-errors/index.md); traps do not unwind; explicit [std.error](../../stdlib/error.md) result mapping and contexts |
| Iteration | [Loops, comprehensions, and native generators](../../language/09-iteration/index.md); [local serial pipelines](../../language/09-iteration/06-pipelines.md) with borrowed sources, fused adapters including `chain`, `flat_map`, and callback-free `filter_value`, reductions, `next(p)`, lending as `&mut Iter[T]`, and [parallel pipelines](../../language/09-iteration/06-pipelines.md#parallel-pipelines) on a pool with `.par(&pool)` over owned or borrowed lists and ranges; no reference yield or public borrow across suspension |
| Built-ins | [Numeric, text, and collection operations](../../facilities/01-builtins/index.md); explicitly fallible allocating operations; [columnar lists](../../facilities/01-builtins/clists.md) for primitive-field classes with borrowed scalar pipelines |
| Standard library | Embedded [std.math](../../stdlib/math.md), [std.path](../../stdlib/path.md), [std.fs](../../stdlib/fs.md), [std.deque](../../stdlib/deque.md), and [std.bytes](../../stdlib/bytes.md); typed errors, Linux paths/metadata and walking, owned double-ended queues, and compact byte buffers. [std.time](../../stdlib/time.md) adds checked durations, monotonic deadlines, and wall timestamps. [std.io](../../stdlib/io.md) adds partial-progress byte streams, retry helpers, and fixed-capacity buffering over files, process streams, and memory. [std.encoding](../../stdlib/encoding.md) adds strict hex/base64 codecs and explicit-endian integer packing. [std.url](../../stdlib/url.md) adds strict RFC 3986 URL parsing, component-aware percent encoding, and query pairs. [std.collections](../../stdlib/collections.md) adds binary heaps. [std.complex](../../stdlib/complex.md) adds `f64` complex numbers with arithmetic operators. [std.cache.lru](../../stdlib/cache-lru.md) adds fixed-capacity least-recently-used caches. [std.csv](../../stdlib/csv.md) adds bounded streaming CSV records and writers. [std.random](../../stdlib/random.md) adds caller-owned seeded generators and [std.secrets](../../stdlib/secrets.md) OS-backed secret bytes and tokens. [std.crypto](../../stdlib/crypto.md) adds digests, HMAC, BLAKE3 hashing/key derivation, constant-time comparison, and [AEAD, Ed25519, X25519, and HKDF](../../stdlib/crypto-advanced.md). [std.compress](../../stdlib/compress.md) adds bounded gzip, zlib, and DEFLATE streams. [std.archive](../../stdlib/archive.md) adds TAR and ZIP reading, writing, and confined extraction. [std.regex](../../stdlib/regex.md) adds linear-time regular expressions with explicit resource limits. [std.db.sqlite](../../stdlib/sqlite.md) adds SQLite databases through typed prepared statements and owned transactions. [std.json](../../stdlib/json.md) adds strict, bounded JSON: a resumable event decoder, a validating encoder, and a value tree. [std.log](../../stdlib/log.md) adds leveled structured events with explicit, bounded sinks. [std.toml](../../stdlib/toml.md) adds strict, bounded TOML 1.0 parsing and writing over a value tree. [std.env](../../stdlib/env.md) reads variables and the working directory, and [std.process](../../stdlib/process.md) spawns owned children from argument vectors without a shell, with pipes, bounded output collection, signals, and explicit reaping. [std.ready](../../stdlib/ready.md) adds readiness waits on one handle or many (selectors) under a deadline and a cancellation token that wakes them directly. [std.actor](../../stdlib/actor.md) runs supervised actors over std.ready on x86-64 and AArch64 GNU/Linux, each with a limited heap that a trap discards, bounded mailboxes of copied messages, timers, request-reply and opt-in restart. [std.signal](../../stdlib/signal.md) delivers `SIGTERM` and `SIGINT` as an event, so a server can drain when its supervisor stops it. [std.net](../../stdlib/net.md) adds TCP and UDP sockets, IP address parsing, and cancellable name lookup under the same deadlines. [std.tls](../../stdlib/tls.md) adds verified TLS client and server streams over those sockets, with client certificates, ALPN, SNI certificate selection, revocation lists, and selector-driven use. [std.http](../../stdlib/http.md) adds bounded HTTP/1.1 message framing with streamed bodies and strict rejection of ambiguous framing. [std.http.server](../../stdlib/http-server.md) serves it, and HTTPS through std.tls, with typed routes, bounded workers and admission, idle connections parked on a selector, per-phase deadlines, and graceful shutdown; its [qualification](../../stdlib/http-qualification.md) lists the production gates it passes. [std.http.client](../../stdlib/http-client.md) sends requests over pooled connections with deadlines, bounded redirects, an explicit proxy, and streamed uploads, shares one pool between threads through `Shared`, and std.http.https adds verified `https` with `CONNECT` tunnels. [std.http.body](../../stdlib/http-body.md), [std.http.cookie](../../stdlib/http-cookie.md) and [std.http.proxy](../../stdlib/http-proxy.md) add bounded forms, JSON and multipart uploads, validated cookies, and trusted-proxy client addresses for handlers. [std.http.files](../../stdlib/http-files.md) serves static files confined to a root directory; cookies can be signed. [std.test](../../stdlib/test.md) adds assertions that report their caller's position, fixtures, fake clocks and streams, and allocation and file failure injection for `plenty test`. [std.diff](../../stdlib/diff.md) adds Myers and patience differences over lists, bytes, and text tokens, with unified-diff output |
| I/O | [Text/byte streams, raw Unix paths, and owned UTF-8 files](../../facilities/02-io/index.md); direct file iteration unsupported |
| Concurrency | [Threads, channels, pools, futures, and parallel operations](../../facilities/03-concurrency/index.md), with [atomics](../../stdlib/atomic.md) and [mutexes](../../facilities/03-concurrency/mutex.md) shared through scoped-thread borrows or atomically counted [`Shared[T]`](../../facilities/01-builtins/shared.md) owners; certified worker effects, serial ordinary loops; no weak handles |
| Interoperability | [Trusted C imports, exports, metadata, and runtime loading](../../facilities/04-interop/index.md) |
| Editor support | [Language server](../01-building/language-server.md) with diagnostics, hover, go to definition, and completion, configured for [Neovim](../01-building/neovim.md); generic bodies resolve per instantiation |
| Native toolchain | [Commands and artifacts](../01-building/index.md), and [per-function IR and assembly dumps](dump.md); native `x86_64-unknown-linux-gnu` and `aarch64-unknown-linux-gnu`, linking with the matching host `cc`; [release requirements](../01-building/installing.md) and [ARM qualification](../../../development/linux-aarch64.md) distinguish implementation from tested deployment environments |

The ARM path uses generic ARMv8-A instructions, scalar `std.simd`, Linux ELF,
and the AAPCS64 C ABI. It is a release platform: the release workflow builds the
compiler and both optional engines in the glibc 2.28 image on native ARM
runners, runs the full suite there, and smoke-tests the archives in AlmaLinux 8
and Debian 13. Kernels older than the one tested, page sizes other than 4 KiB
and other distributions are not tested; see the
[ARM development notes](../../../development/linux-aarch64.md). x86-64 retains
its SSE2 baseline. Selecting `--target` or a linker does not turn an installed
compiler into a cross-compiler.

Native emission for `aarch64-apple-darwin` and `x86_64-pc-windows-msvc` is
experimental. It includes target ABI, Mach-O/COFF objects and native linker
invocation. Releases publish an experimental core compiler archive for each,
without the optional engines, which are Linux ELF libraries. Native CI and the
release workflow pass compiler/runtime builds and unit tests, platform-boundary
checks, and compilation and execution of a generated callback/result program on
both operating systems. Runtime and standard-library capabilities remain
incomplete, including actor recovery and several OS services, and these checks
do not establish standard-library parity; see
[experimental macOS and Windows downloads](../01-building/installing.md#experimental-macos-and-windows-downloads).

There is no interpreter, REPL, JIT, async/await, inheritance, dynamic attributes,
or exception unwinding. Future work and priorities remain in the
[backlog](../../../backlog.md).
