# Support index

The reference describes the supported subset, not Python's full API. Detailed
restrictions live with their contracts.

| Area | Contract and principal limits |
|---|---|
| Source and modules | [Declarations, imports, visibility, and entrypoints](../../language/02-source/index.md); one source root per package, no import cycles or re-exports |
| Packages | [`plenty.toml`, path and Git dependencies pinned in `plenty.lock`, version requirements, workspaces, `plenty add`/`fetch`/`update`, per-target build reuse, debug/release profiles, `plenty test` with per-process test functions run in parallel under optional timeouts, and `plentyc --package-graph`](../01-building/packages.md); no registry or version selection |
| Types and data | [Types](../../language/03-types/index.md); fixed layouts and recursive data through heap boundaries |
| Expressions | [Operators, assignment, and control flow](../../language/04-expressions/index.md); blocks and expressions [nest to 64 levels](../../language/04-expressions/index.md#nesting) |
| Ownership | [Moves, checked borrows, returned references, and cleanup](../../language/05-ownership/index.md); general stored references unsupported |
| Functions | [Named functions and concrete closures](../../language/06-functions/index.md); explicit fallible [shared-call erasure](../../language/06-functions/05-boxed-callables.md) |
| Generics | [Concrete specialization and structural protocols](../../language/07-generics/index.md); no dynamic protocol dispatch |
| Errors and resources | [Sums, propagation, allocation, and context scopes](../../language/08-errors/index.md); traps do not unwind; explicit [std.error](../../stdlib/error.md) contexts |
| Iteration | [Loops, comprehensions, and native generators](../../language/09-iteration/index.md); no reference yield or public borrow across suspension |
| Built-ins | [Numeric, text, and collection operations](../../facilities/01-builtins/index.md); explicitly fallible allocating operations |
| Standard library | Embedded [std.math](../../stdlib/math.md), [std.path](../../stdlib/path.md), [std.fs](../../stdlib/fs.md), [std.deque](../../stdlib/deque.md), and [std.bytes](../../stdlib/bytes.md); typed errors, Linux paths/metadata and walking, owned double-ended queues, and compact byte buffers. [std.time](../../stdlib/time.md) adds checked durations, monotonic deadlines, and wall timestamps. [std.io](../../stdlib/io.md) adds partial-progress byte streams, retry helpers, and fixed-capacity buffering over files, process streams, and memory. [std.encoding](../../stdlib/encoding.md) adds strict hex/base64 codecs and explicit-endian integer packing. [std.url](../../stdlib/url.md) adds strict RFC 3986 URL parsing, component-aware percent encoding, and query pairs. [std.collections](../../stdlib/collections.md) adds binary heaps and [std.iter](../../stdlib/iter.md) generator adapters. [std.csv](../../stdlib/csv.md) adds bounded streaming CSV records and writers. [std.random](../../stdlib/random.md) adds caller-owned seeded generators and [std.secrets](../../stdlib/secrets.md) OS-backed secret bytes and tokens. [std.crypto](../../stdlib/crypto.md) adds SHA-256/SHA-512 digests, HMAC, and constant-time comparison. [std.compress](../../stdlib/compress.md) adds bounded gzip, zlib, and DEFLATE streams. [std.archive](../../stdlib/archive.md) adds TAR and ZIP reading, writing, and confined extraction. [std.regex](../../stdlib/regex.md) adds linear-time regular expressions with explicit resource limits. [std.db.sqlite](../../stdlib/sqlite.md) adds SQLite databases through typed prepared statements and owned transactions. [std.json](../../stdlib/json.md) adds strict, bounded JSON: a resumable event decoder, a validating encoder, and a value tree. [std.log](../../stdlib/log.md) adds leveled structured events with explicit, bounded sinks. [std.toml](../../stdlib/toml.md) adds strict, bounded TOML 1.0 parsing and writing over a value tree. [std.env](../../stdlib/env.md) reads variables and the working directory, and [std.process](../../stdlib/process.md) spawns owned children from argument vectors without a shell, with pipes, bounded output collection, signals, and explicit reaping. [std.ready](../../stdlib/ready.md) adds readiness waits on one handle or many (selectors) under a deadline and a cancellation token that wakes them directly. [std.net](../../stdlib/net.md) adds TCP and UDP sockets, IP address parsing, and cancellable name lookup under the same deadlines. [std.tls](../../stdlib/tls.md) adds verified TLS client and server streams over those sockets, with client certificates, ALPN, SNI certificate selection, revocation lists, and selector-driven use. [std.http](../../stdlib/http.md) adds bounded HTTP/1.1 message framing with streamed bodies and strict rejection of ambiguous framing. [std.http.server](../../stdlib/http-server.md) serves it with routing, bounded workers and admission, per-phase deadlines, and graceful shutdown. [std.http.client](../../stdlib/http-client.md) sends requests over pooled connections with deadlines, bounded redirects, and an explicit proxy. [std.http.body](../../stdlib/http-body.md), [std.http.cookie](../../stdlib/http-cookie.md) and [std.http.proxy](../../stdlib/http-proxy.md) add bounded forms, JSON and multipart uploads, validated cookies, and trusted-proxy client addresses for handlers. [std.test](../../stdlib/test.md) adds assertions that report their caller's position, fixtures, fake clocks and streams, and allocation and file failure injection for `plenty test` |
| I/O | [Text/byte streams, raw Unix paths, and owned UTF-8 files](../../facilities/02-io/index.md); direct file iteration unsupported |
| Concurrency | [Threads, channels, pools, futures, and parallel operations](../../facilities/03-concurrency/index.md); certified worker effects, serial ordinary loops |
| Interoperability | [Trusted C imports, exports, metadata, and runtime loading](../../facilities/04-interop/index.md) |
| Native toolchain | [Commands and artifacts](../01-building/index.md); `x86_64-unknown-linux-gnu` only |

There is no interpreter, REPL, JIT, async/await, inheritance, dynamic attributes,
or exception unwinding. Future work and priorities remain in the
[backlog](../../../backlog.md).
