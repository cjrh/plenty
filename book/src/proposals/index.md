# Proposals

Proposals record design rationale, alternatives, open questions, and technical
dependencies. Their stages and acceptance criteria are design sketches, not
active work queues or delivery commitments. Some proposals retain historical
syntax and assumptions.

The [backlog](../backlog.md) is the only maintained list of future work and
priorities. The [reference](../design/index.md) describes implemented behavior;
where a proposal and the reference disagree about current behavior, the reference
is correct. The [foundation batch record](next-work-queue.md) is historical.
