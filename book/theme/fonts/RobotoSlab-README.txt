Roboto Slab
===========

Source: https://fonts.google.com/specimen/Roboto+Slab
The variable TrueType font is copied without modification from the
Roboto_Slab.zip archive downloaded from Google Fonts on 2026-11-02.
It provides upright weights 100–900; italic text uses browser synthesis.
Licence: Apache License 2.0; see RobotoSlab-LICENSE.txt.

mdBook copies the files in this directory into each built book. The custom
stylesheet ../typography.css uses its resource helper so the font URL follows
mdBook fingerprinting and works at every chapter depth and version prefix.
The font is served locally; no Google Fonts connection is needed.
